# 輕鬆買

方便長輩使用的單人離線購物 PWA，支援地點分類、採買日期與順序、常買品項、購買金額及歷史紀錄。

## 在 iPhone 使用

使用 Safari 開啟本儲存庫的 GitHub Pages 網址，到「使用設定」等候「離線使用已準備好」，再從 Safari 分享選單加入主畫面。

清單與購買紀錄只儲存在目前裝置。換手機前，請在 App 下載備份；備份不要上傳到這個儲存庫。

## 發布

此儲存庫包含已建置的完整靜態網站。在 Settings → Pages 選擇 Deploy from a branch、main、/(root)。更新時需上傳整批檔案，以維持離線資產完整性。

App 版本：`7b2fe8a4df29`。主畫面使用新版購物清單圖示。
